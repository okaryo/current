# Current

Current is a local-first desktop app designed to help you stay focused on the current task.

It combines:

- Pomodoro timer
- TODO management
- Quick work logging
- Keyboard-first workflow

Current is designed to reduce friction between thinking and doing.

## Philosophy

Current is designed to help you:

- focus on the current task
- maintain a working rhythm

Current focuses on the present, not optimization.

## Main Features

- Pomodoro timer
- Keyboard-first workflow
- Quick TODO management
- Quick work logging
- Rhythm reminders
- Local data storage

## What Current Is NOT

Current is not:

- a team collaboration tool
- a cloud-sync platform
- a project management system
- a knowledge management tool
- a detailed analytics dashboard
- a social productivity app

Current focuses on the present, not optimization.
